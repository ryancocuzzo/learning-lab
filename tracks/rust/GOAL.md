# Goal

## Goal

The goal here is to build a K-Nearest Neighbors (KNN) algorithm from scratch using Rust. This will involve implementing core data structures, distance calculations, and the classification/regression logic.

### Acceptance criteria

A Rust program that..

- [ ] Defines data structures for data points and training data
- [ ] Implements distance calculation functions
    - [ ] Euclidean distance
- [ ] Implements KNN algorithm
    - [ ] Finds k nearest neighbors for a given query point
    - [ ] Handles classification (majority voting)
- [ ] Handles edge cases
    - [ ] Empty training set
    - [ ] k > number of training samples
    - [ ] Ties in distance
- [ ] Includes unit tests
- [ ] Demonstrates usage with example data
- [ ] Uses idiomatic Rust patterns
    - [ ] Ownership and borrowing
    - [ ] Error handling
    - [ ] Option/Result types

### Skills practiced

- Rust fundamentals (ownership, borrowing, lifetimes)
- Data structures (vectors, tuples, structs)
- Algorithm implementation
- Unit testing in Rust
- Error handling with Result/Option
- Generic programming (if applicable)

## Artifacts produced

- KNN implementation library
- Unit tests
- Example usage demonstrating classification
