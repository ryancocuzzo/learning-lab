# Goal

## Goal

The goal here is to build a K-Nearest Neighbors (KNN) algorithm from scratch using TS. This will involve implementing core data structures, distance calculations, and the classification/regression logic.

### Acceptance criteria

A TS program that..

- [x] Defines data structures for data points and training data
- [x] Implements distance calculation functions
    - [x] Euclidean distance
- [x] Implements KNN algorithm
    - [x] Finds k nearest neighbors for a given query point
    - [x] Handles classification (majority voting)
- [x] Handles edge cases
    - [x] Empty training set
    - [x] k > number of training samples
    - [x] Ties in distance
- [x] Includes unit tests
- [x] Demonstrates usage with example data
- [x] Uses good software patterns

### Skills practiced

- Data structures (vectors, tuples, structs)
- Algorithm implementation
- Unit testing
